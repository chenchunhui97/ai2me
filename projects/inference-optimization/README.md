# 推理优化项目

对应 T22、T25，当前尚未开始。目标是在实际可用硬件上完成一个可复现的优化闭环，规模可小，结论必须真实。

| 内容 | 必须保存的证据 |
|---|---|
| 问题与目标 | workload、SLO、基线和瓶颈假设 |
| 环境 | GPU/互连、CPU、驱动、CUDA、框架 commit、模型版本与精度 |
| 正确性 | 对齐命令、容差、边界情况，量化实验还需质量验证 |
| 改动 | 代码、patch、设计理由和适用范围 |
| 实验 | 固定配置、warmup/同步方式、重复次数、延迟分位数和吞吐 |
| 结果 | 小型原始结果、profile 摘要、改善或退化、误差与局限 |
| 复现 | 从环境到运行的完整命令与实际输出 |

使用 [实验模板](../../templates/experiment.md)。理论估算和 CPU 模拟可以辅助设计，不能替代最终硬件性能验证。真实多卡、昇腾和生产集群经验尚未取得时保持缺口标记。
