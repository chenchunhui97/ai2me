# 目标岗位与能力缺口

来源：本目录三张用户提供的岗位截图，2026-11-07 建档。岗位包含“推理优化工程师”和“大模型推理优化高级工程师”，要求有差异。

| 能力 | JD 中的要求 | 本计划覆盖 | 仍需明确的边界 |
|---|---|---|---|
| 模型计算 | Transformer、LLM 推理流程 | T01～T07 | 当前尚未独立验收 |
| 引擎开发 | vLLM/SGLang/TensorRT-LLM 源码、二次开发 | T10～T13、T18、T24 | 主攻 vLLM，TensorRT-LLM 深入开发后续专项 |
| 算子 | CUDA/CANN/Ascend C、FlashAttention/PagedAttention | T14～T17、T23 | NVIDIA 实测需要 GPU，真实 NPU 适配不由阅读替代 |
| 性能分析 | 瓶颈定位、延迟、吞吐 | T08～T09、T19、T22、T25 | 需要真实 profile 与对照实验 |
| PD 分离 | 实际优化落地、KV 传输、调度和拓扑 | T20～T22 | 原型和多机落地分别记录 |
| 分布式 | RDMA/TCP、NCCL/HCCL、大规模集群 | T20～T21 | 多卡/多机实测和生产规模经验后续积累 |
| 新技术与模型 | 投机解码、稀疏注意力、动态批处理、多模态 | T18、T24 | 先完成基础，扩展需额外项目 |
| 特定框架 | DSpark 部署与调优 | T24 后续清单 | 截图未给出确切项目，需核实实现与版本 |
| 资历 | 3 年以上相关开发经验，部分岗位硕士及以上 | 不折算为课程任务 | 学习计划不自动满足资历要求 |
